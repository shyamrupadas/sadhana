# 02: Регистрация, вход и защищённый доступ

**What to build:** Новый пользователь может зарегистрироваться, существующий — войти и выйти, а пользователь без действующей сессии не видит защищённую страницу. Эти действия защищены короткими браузерными сценариями.

**Blocked by:** 01 — Отметка привычки и тестовый контур

**Status:** ready-for-agent

- [ ] Один браузерный тест проверяет перенаправление гостя с защищённой страницы на вход.
- [ ] Один браузерный тест проверяет регистрацию и переход на главную страницу.
- [ ] Один браузерный тест проверяет вход, выход и недоступность защищённой страницы после выхода.
- [ ] Тесты используют точные подмены API и наблюдаемые элементы и адреса; не подключаются к настоящему backend или базе данных.
- [ ] Не добавлены проверки размеров экрана, вариантов валидации и состояния токена после истечения срока без отдельного подтверждения их критичности.
- [ ] Целевые браузерные тесты, `pnpm lint`, `pnpm build` и локальный `pnpm test` проходят; путь доступа вручную проверен через `pnpm dev:web`.
