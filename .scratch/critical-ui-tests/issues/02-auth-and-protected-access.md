# 02: Регистрация, вход и защищённый доступ

**What to build:** Защитить браузерными UI-тестами доступ к Sadhana: новый пользователь регистрируется, существующий входит и выходит, а гость не попадает на защищённую страницу. Поломка любого из этих действий может закрыть доступ ко всем записям дня и привычкам, даже если серверные маршруты работают.

**Blocked by:** 01 — Отметка привычки и тестовый контур

## Контекст и границы

- Проверять три наблюдаемых пользовательских пути в браузере, используя тестовый контур из тикета 01. Тесты маршрутов API уже защищают серверную авторизацию, но не переходы между страницами и состояние сессии в браузере.
- Как в ShlokaHub, подменять API точными ответами и проверять доступные пользователю элементы и адреса. Сохранить небольшой набор: перенаправление гостя, регистрация, вход и выход; дополнительные варианты добавлять только после подтверждения их критичности.
- Полный исходный запрос и общие решения по тестированию находятся в [родительской спецификации](../spec.md). Прочитать её перед реализацией.
