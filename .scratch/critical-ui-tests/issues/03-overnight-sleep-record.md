# 03: Сохранение ночного сна

**What to build:** Пользователь записывает вечерний отбой и утренний подъём через полночь и после обновления страницы видит сохранённые данные сна и длительность.

**Blocked by:** 01 — Отметка привычки и тестовый контур

**Status:** ready-for-agent

- [ ] Один браузерный тест вводит вечерний отбой и утренний подъём в запись дня и проверяет ночной переход через полночь.
- [ ] После обновления страницы тест проверяет сохранённые время отбоя, время подъёма и длительность сна.
- [ ] Подмена API хранит состояние между запросами, явно диагностирует неожиданные запросы и не обращается к настоящему backend или базе данных.
- [ ] Не добавлены отдельные тесты дневного сна, статистики сна и такого же отката ошибки сохранения, как для отметки привычки.
- [ ] Целевой браузерный тест, `pnpm lint`, `pnpm build` и локальный `pnpm test` проходят; путь записи сна вручную проверен через `pnpm dev:web`.
