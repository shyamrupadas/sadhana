## Question

Подготовить `.scratch/database-environments/spec.md` через `to-spec` на основе принятых решений, чтобы пользователь мог согласовать проверяемое описание перехода перед публикацией реализационных тикетов.

Спецификация должна определить конфигурацию окружений и проверку целей, интерфейсы команд статуса/миграций/восстановления/репетиции, получение совместимого исходника из Git, генератор синтетических данных, необходимые проверки и порядок первого включения постоянного dev. Зафиксировать критерии приёмки и зависимости от фактических возможностей аккаунта Neon; не подменять согласованный путь обычной копией production.

Результат задачи — спецификация для согласования, не реализация и не создание/сброс внешних БД. Точные реализационные тикеты публикуются после принятия спецификации.
