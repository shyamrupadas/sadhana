# 04: Проверка SQL в production-образе без фиксированного количества

**What to build:** Проверка собранного production-образа подтверждает точный набор и содержимое SQL той же сборки. Добавление следующей миграции не требует вручную менять число ожидаемых файлов.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Ожидаемый набор относительных имён и checksum получается из SQL-исходников проверяемой сборки; упакованные файлы сравниваются с этим независимым набором, а не с манифестом, рассчитанным только из содержимого образа.
- [ ] Пропущенный, лишний, переименованный или изменённый SQL приводит к отказу проверки. Не остаётся требования «ровно шесть» или другой константы количества.
- [ ] Новый корректно добавленный SQL попадает в образ и проходит сверку без изменения ожидаемого числа. Проверка не изменяет реальные исторические SQL и не добавляет тестовую миграцию в выпускаемую цепочку ради демонстрации.
- [ ] Сохраняются проверки non-root образа, наличия production-точек запуска/контракта, отсутствия frontend и лишних dev-инструментов, а также проверки старта на Railway PORT. Выпуск не начинает автоматически применять SQL при сборке/старте.
- [ ] Подтверждены положительный случай и отказ при отсутствующем/искажённом упакованном SQL. Проверка production-образа выполнена без подключения к Neon; PostgreSQL в обязательный CI не добавляется.

## Проверка и границы

Эта задача не зависит от новых CLI-команд и может выполняться параллельно с защитой окружений. После последующих изменений упаковки итоговая проверка повторяется в приёмке перехода. Внешние настройки Railway и production-БД здесь не меняются.

## Участие пользователя

Когда проверку или действие можно либо поручить агенту, либо выполнить самому через аккаунт/сервис, сначала объяснить цель и ожидаемый результат и предложить пользователю выбор. Этот шаг ждёт ответа; независимая работа может продолжаться. После явного делегирования действовать в согласованном объёме без повторного запроса по тому же шагу. Это предпочтение пользователя от 2026-10-15 действует и для фактов, доступных агенту.
