# 01: Web в pnpm workspace

**What to build:** Разработчик может запускать и собирать прежний web из общего workspace, а его выпуск по-прежнему создаёт рабочий сайт на прежнем адресе и обращается к действующему API.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Web перенесён как отдельный приватный пакет pnpm; чистая установка из корня, lint, typecheck и production-сборка проходят на закреплённых Node 24 и pnpm.
- [ ] Сохранились маршруты, три слоя фронтенда, публичные входные точки фич, PWA, production API URL и поведение текущего клиента.
- [ ] Общий граф Turbo собирает web без ручной подготовки зависимостей; web можно запустить отдельно.
- [ ] Workflow web подготовлен к установке и сборке из workspace и публикации артефакта web в прежний каталог VPS с прежними SSH-проверками, не меняя адрес и секреты.
- [ ] Быстрая проверка локального сайта подтверждает вход, главный экран и статистику со старым API; production-публикация оставлена тикету переключения.
