# 06: Чтение и запись записей дня через контракт

**What to build:** Пользователь читает недавние записи дня и сохраняет данные сна через общий контракт, сохраняя прежние правила московских дат и расчёта сна.

**Blocked by:** 03 — Первый сквозной TypeSpec-срез: список привычек

**Status:** ready-for-agent

- [ ] Список записей, получение по дате и сохранение сна описаны в TypeSpec и доступны через generated-клиент и `ApiHandlers`; Fastify сохраняет методы, пути, JSON Schema и текущие ответы.
- [ ] Контракт отражает пять московских дней в списке, обязательный nullable `napDuration`, необязательные nullable `bedtime`/`wakeTime`, `404` для отсутствующей записи и прежний расчёт `duration`.
- [ ] Web сохраняет существующий ключ списка сна, отмену запроса, оптимистичное обновление, откат при ошибке и повторное чтение; работает со старым API до переключения.
- [ ] HTTP-тесты проверяют создание/чтение записи, отсутствие времён, нулевой дневной сон, переход дат и фактические ошибочные ответы без намеренного исправления старой ошибки валидации.
