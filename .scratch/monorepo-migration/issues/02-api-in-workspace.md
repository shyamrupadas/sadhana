# 02: API в общем workspace

**What to build:** Разработчик запускает web и действующий Fastify API вместе из одной монорепы, а существующие HTTP-сценарии остаются работоспособными до перехода на новый контракт.

**Blocked by:** 01 — Web в pnpm workspace

**Status:** ready-for-agent

- [ ] Зафиксирован SHA актуального локального backend-коммита; перенесены только его отслеживаемые исходники без Git-истории, секретов и артефактов сборки.
- [ ] API стал отдельным приватным пакетом pnpm; его сборка, lint и прежние быстрые тесты проходят из корня workspace.
- [ ] Общая команда разработки запускает оба приложения, а отдельные команды запускают каждое; после чистой установки не требуется ручная сборка или копирование файлов.
- [ ] Fastify слушает прежний порт и интерфейс, а HTTP-методы, пути, ответы, auth/cookie и SQL 001–006 не меняются от структурного переноса.
- [ ] Контрольные HTTP-запросы к локальному API и web подтверждают работу прежних сценариев; Railway пока использует старый репозиторий.
