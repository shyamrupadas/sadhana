# 13: Выпуск нового web со старым API

**What to build:** Пользователь получает новый web из монорепозитория на прежнем адресе, пока действующий API остаётся старым; эта переходная пара работает до переключения Railway.

**Blocked by:** 12 — Репетиция мигратора на временной ветке Neon

**Status:** ready-for-agent

- [ ] Общий коммит проходит обязательный CI и автоматически выпускает web из `master` через прежний GitHub Actions → SSH → VPS; проверены опубликованный артефакт, SHA и встроенный API URL.
- [ ] На действующем сайте со старым API проверены вход, обновление сессии, привычки, записи дня, статистика, навигация и обновление PWA без ошибок ресурсов.
- [ ] API Railway всё ещё привязан к прежнему backend-репозиторию; его домены, переменные и данные Neon не изменены этим выпуском.
- [ ] При несовместимости или сбое web дальнейшее переключение остановлено; известен и проверен способ повторно выпустить прежнюю рабочую версию web.
