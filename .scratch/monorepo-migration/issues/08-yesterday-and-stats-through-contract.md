# 08: Вчерашний сон и статистика через контракт

**What to build:** Пользователь видит проверку вчерашнего сна и статистику за неделю, месяц и год через общий контракт с прежними значениями и пустыми состояниями.

**Blocked by:** 03 — Первый сквозной TypeSpec-срез: список привычек

**Status:** ready-for-agent

- [ ] Проверка вчерашнего сна и статистика описаны в TypeSpec и реализованы через generated-клиент, `ApiHandlers` и прежние Fastify runtime-проверки.
- [ ] Проверка использует фактическую пару «отбой позавчера — подъём вчера» в московской календарной зоне; статистика сохраняет nullable значения для пустых периодов.
- [ ] Главный экран и экран статистики сохраняют загрузку, ошибки, форматирование и повторные запросы; новый web работает со старым API до Railway-переключения.
- [ ] HTTP-тесты проверяют границы дат, пустые и заполненные периоды, авторизацию и форму ответов.
