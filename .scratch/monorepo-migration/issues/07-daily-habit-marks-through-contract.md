# 07: Отметки привычек в записи дня через контракт

**What to build:** Пользователь ставит и снимает отметку привычки в записи дня через общий контракт, а экран немедленно показывает изменение и возвращает прежнее состояние при сбое.

**Blocked by:** 06 — Чтение и запись записей дня через контракт

**Status:** ready-for-agent

- [x] Установка/изменение и удаление отметки описаны в TypeSpec и доступны через generated-клиент, `ApiHandlers` и прежние Fastify runtime-проверки.
- [x] Сохранились фактические ветки: создание записи дня при первой отметке, допустимый неизвестный ключ, `404` для отсутствующей записи при удалении и успешное удаление отсутствующей отметки в существующем дне.
- [x] Web использует тот же кэш списка записей дня, отменяет конкурирующее чтение, оптимистично обновляет отметку, откатывает ошибку и повторно запрашивает серверное состояние.
- [ ] HTTP- и сценарные проверки подтверждают оба направления изменения, ошибки и совместимость новой web-версии со старым API.

## Comments

- HTTP-тесты Fastify и интеграционный тест generated-клиента с существующими маршрутами проверяют установку, изменение и удаление отметки, чтение, `401`, `404` и прежний `500` для неверного тела. `pnpm lint`, `pnpm typecheck`, `pnpm build` и `pnpm test` прошли.
- Сценарий web с оптимистичным откатом и повторным чтением, а также прямую проверку с прежним API пока не удалось выполнить: MCP `chrome-devtools` недоступен в текущей среде. Тестовую инфраструктуру web не добавляем по решению пользователя.
