# 07: Отметки привычек в записи дня через контракт

**What to build:** Пользователь ставит и снимает отметку привычки в записи дня через общий контракт, а экран немедленно показывает изменение и возвращает прежнее состояние при сбое.

**Blocked by:** 06 — Чтение и запись записей дня через контракт

**Status:** ready-for-agent

- [ ] Установка/изменение и удаление отметки описаны в TypeSpec и доступны через generated-клиент, `ApiHandlers` и прежние Fastify runtime-проверки.
- [ ] Сохранились фактические ветки: создание записи дня при первой отметке, допустимый неизвестный ключ, `404` для отсутствующей записи при удалении и успешное удаление отсутствующей отметки в существующем дне.
- [ ] Web использует тот же кэш списка записей дня, отменяет конкурирующее чтение, оптимистично обновляет отметку, откатывает ошибку и повторно запрашивает серверное состояние.
- [ ] HTTP- и сценарные проверки подтверждают оба направления изменения, ошибки и совместимость новой web-версии со старым API.
