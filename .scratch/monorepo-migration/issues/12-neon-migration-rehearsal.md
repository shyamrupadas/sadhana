# 12: Репетиция мигратора на временной ветке Neon

**What to build:** Оператор получает подтверждение, что production-подобная база принимает журнал исторических миграций и новый Pre-Deploy не запускает SQL 001–006 повторно, не затрагивая рабочую Neon.

**Blocked by:** 11 — CI и Docker для независимых выпусков

**Status:** ready-for-agent

- [ ] Установлена именно та ветка Neon, которую использует действующий Railway-сервис; из неё создана временная изолированная ветка без выгрузки персональных данных.
- [ ] На временной ветке сверены схема и признаки данных 001–006, затем однократно записаны подтверждённые версии и контрольные суммы без исполнения исторических SQL.
- [ ] Мигратор из проверенного production-образа с direct URL временной ветки успешно запускается дважды; журнал остаётся из шести подтверждённых строк, пользовательские таблицы не преобразуются повторно.
- [ ] Проверены лог, код завершения и ошибка при несовпадающей сумме; результаты зафиксированы без секретов, а production-база не менялась.
- [ ] Временная ветка остаётся доступной до конца переключения и удаляется после приёмки.
