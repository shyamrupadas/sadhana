# 05: Создание, переименование и удаление привычек через контракт

**What to build:** Пользователь управляет привычками через общий контракт без изменения списка, ответов и видимых ошибок.

**Blocked by:** 03 — Первый сквозной TypeSpec-срез: список привычек

**Status:** awaiting-human-review
Accepted: 2026-10-04

- [x] Создание, переименование и удаление привычки описаны в TypeSpec и реализованы через generated-клиент, единый backend-интерфейс и Fastify-адаптеры с прежними runtime-проверками.
