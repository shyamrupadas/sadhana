# 03: Первый сквозной TypeSpec-срез: список привычек

**What to build:** Пользователь видит свой список привычек через общий генерируемый контракт, а разработчик получает работающий путь TypeSpec → клиент web → Fastify без одновременного переписывания остальных операций.

**Blocked by:** 02 — API в общем workspace

**Status:** ready-for-agent

- [ ] В workspace появился пакет общего контракта с TypeSpec-источником и детерминированной генерацией OpenAPI, TypeScript-типов, именованного `ApiClient` и backend `ApiHandlers` для первой операции.
- [ ] Список привычек загружается в web через `ApiClient` с прежним bearer/refresh-транспортом и тем же ключом кэша; Fastify обслуживает операцию через типизированный обработчик и сохраняет runtime JSON Schema.
- [ ] HTTP-проверка через Fastify подтверждает статус, тело, 401 и принадлежность списка пользователю; экран web сохраняет загрузку и ошибку.
- [ ] Генератор отвергает неподдержанную конструкцию, а повторная генерация не меняет коммитимые артефакты; остальные операции продолжают работать через прежний клиент на время перехода.
- [ ] Новый контракт подхватывается обоими приложениями после чистой установки и при изменении TypeSpec в режиме разработки.
