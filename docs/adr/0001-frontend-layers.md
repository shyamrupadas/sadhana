# Использовать слои app, features и shared во фронтенде

В Sadhana сохраняем три верхнеуровневых слоя фронтенда: `app` запускает приложение и собирает маршруты, `features` содержит пользовательские сценарии, `shared` — общие компоненты, модели и API-инфраструктуру. Для текущего масштаба приложения эти границы дают место новым функциям без дополнительных обязательных слоев. Направление зависимостей и входные точки фич проверяются через ESLint.

**Альтернативы и компромисс**

- Плоская структура требует меньше начальных правил, но позволяет зависимостям между сценариями расти без явной границы.
- Дополнительные верхнеуровневые слои заранее формализуют больше ролей, но увеличивают стоимость размещения и переноса кода до появления реальной потребности.

**Последствия**

`shared` не импортирует `features` и `app`, а `features` не импортирует `app`. Внешние импорты фич проходят через `index.ts(x)` или `*.page.tsx`; композиция фич принадлежит `app`. Новую структуру внутри фич и новые слои вводим, когда их требует фактическая сложность, поддерживая правила ESLint и документацию согласованными.
