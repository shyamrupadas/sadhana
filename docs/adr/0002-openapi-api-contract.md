# Использовать OpenAPI как источник типизированного API-контракта фронтенда

HTTP-поверхность, которую ожидает фронтенд Sadhana, описана в `src/shared/api/schema/*.yaml`. Из OpenAPI генерируются TypeScript-типы в `src/shared/api/schema/generated.ts`; `openapi-fetch` и `openapi-react-query` используют их для типизации запросов. Схема служит источником для типов внутри этого репозитория, а ее соответствие работающему серверу требует отдельной проверки.

**Альтернативы и компромисс**

- Ручные типы запросов и ответов проще начать писать, но они могут незаметно разойтись с описанием HTTP API.
- Генерация типов из внешнего backend-контракта убрала бы локальное владение схемой, но такого источника в этом репозитории сейчас нет.

**Последствия**

При изменении API сначала обновляем YAML-схему, затем запускаем `yarn api` и включаем обновленный `generated.ts` в тот же diff. Сгенерированный файл не редактируется вручную. Типизация клиента не заменяет проверку поведения сервера и совместимости с ним.
