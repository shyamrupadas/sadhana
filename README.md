# Sadhana - Трекер сна и привычек

Веб-приложение для отслеживания привычек и сна. Можно установить на устройство как Progressive Web App (PWA).


[https://app.sadhana-tracker.com](https://app.sadhana-tracker.com)

## ✨ Возможности

- 📊 Отметки привычек по дням, создание, переименование и удаление привычек
- 🛏️ Учет времени отхода ко сну, пробуждения и дневного сна
- 📱 PWA с возможностью установки на устройство
- 🔐 Регистрация и вход
- 📈 Статистика сна за год, 30 и 7 дней

## 🛠️ Технологии

- **React 19** - UI библиотека
- **TypeScript** - типизация
- **Vite** - сборщик и dev сервер
- **Tailwind CSS** - стилизация
- **Radix UI** - компоненты
- **React Query** - состояние и кеширование
- **Day.js** - работа с датами
- **React Router** - роутинг

## 📋 Требования

- Node.js >=24.15.0 <25
- Corepack (pnpm 12.4.1 закреплён в `package.json`)

## 🚀 Запуск проекта

### Новый ноутбук или чистый clone

Сценарий для уже подготовленной постоянной dev-БД в Neon.

1. Клонируйте репозиторий и установите зависимости:

```bash
git clone <URL-репозитория> sadhana
cd sadhana
corepack enable
pnpm install --frozen-lockfile
```

2. Восстановите `apps/api/.env.dev.local` из защищённой заметки Bitwarden. Если копии нет, создайте файл из шаблона и заполните значения по комментариям:

```bash
cp -n apps/api/.env.example apps/api/.env.dev.local
```

Подключения берутся из Neon → **dev → Connect**, JWT-ключи и пароль существующих тестовых профилей — из Bitwarden. Подробности — в [инструкции API](apps/api/README.md#локальный-dev).

3. Ограничьте доступ к файлу, проверьте состояние БД и запустите web и API:

```bash
chmod 600 apps/api/.env.dev.local
pnpm db:status
pnpm dev
```

Секреты не приходят с Git; настройки web уже находятся в `apps/web/.env.development`. Новый ноутбук подключается к существующей dev-БД с её текущими данными. Reset, reseed и повторное создание Neon-ветки для этого не нужны. Если `db:status` сообщает об ожидающих миграциях или расхождении истории, следуйте [инструкции мигратора](apps/api/README.md#миграции-postgresql). Первоначальная подготовка самой БД описана [отдельно](apps/api/README.md#первоначальная-настройка-neon).

Локальные адреса: web — `http://localhost:5173/`, API — `http://localhost:8080/`.

### Отдельные dev-процессы

`pnpm dev:web` запускает только web, `pnpm dev:api` — только API. Для обычной разработки с настоящим API используйте совместный `pnpm dev` или запустите оба процесса отдельно.

### Сборка для продакшена

```bash
pnpm build:web
```

API отдельно собирается командой `pnpm build:api`.

### Предварительный просмотр собранного проекта

```bash
pnpm --filter @sadhana/web preview
```

### Линтинг кода

```bash
pnpm lint
```
